# Qadarmann Online Shop

## Overview

Qadarmann Online Shop is a modern e-commerce web application developed using PHP and MySQL. The platform provides customers with a secure and user-friendly online shopping experience while allowing administrators to efficiently manage products, orders, customers, and inventory.

The system is designed to simplify online shopping by offering a responsive interface, secure authentication, and an organized product management system.

---

## Features

### Customer Features

- User Registration and Login
- Browse Products by Category
- Product Search
- Product Details Page
- Shopping Cart
- Wishlist
- Secure Checkout
- Order History
- User Profile Management
- Contact Support
